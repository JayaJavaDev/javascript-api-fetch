# JavaScript API Fetch

## About
Fetch user data from an API using JavaScript with Promises and Async/Await.

## API Endpoint
https://jsonplaceholder.typicode.com/users

## Concepts Used
- Fetch API
- Promises (.then() and .catch())
- Async/Await
- JSON Handling
- Error Handling

## How to Run
```bash
node script.js
```

## Output
Displays an array of user objects in the console.
